# D-Mart Sales Dashboard 2024

## 📊 Project Overview

This project is an interactive Excel dashboard created to analyze D-Mart sales data and generate business insights.

The dashboard helps visualize:

* Category-wise Sales
* Region-wise Sales
* Segment-wise Sales
* Ship Mode Analysis
* Sub-category Performance

## 🛠 Tools Used

* Microsoft Excel
* Pivot Tables
* Charts & Graphs
* Slicers & Filters
* Data Visualization

## 📈 Key Features

* Interactive dashboard with filters
* Business performance insights
* Sales trend analysis
* Clean and professional dashboard design
